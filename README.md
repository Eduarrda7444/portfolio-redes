# 🚀 Portfólio de Laboratórios de Redes

Bem-vindo ao meu repositório de laboratórios e projetos práticos de redes de computadores desenvolvidos no **Cisco Packet Tracer**. Aqui você encontrará documentações e arquivos `.pkt` focados em configurações de infraestrutura e segurança.

* **Conceitos & Protocolos:** IPv4, VPN IPsec, ACLs, Roteamento, Criptografia e Segurança em Redes.
